# Tool logo assets

The course illustrations remain original pastel SVG scenes. Small, static badges identify a technology taught by each program. Matching logos are used in the tool lists, catalogue tags and skill display. Artwork is served locally with versioned URLs; visitors do not contact logo providers.

The supplied Python image was trimmed only to remove transparent margins and resized without changing its artwork or proportions. SVG logos retain their published paths and colors. Generic topics, including SQL, RAG and data modelling, use neutral icons. The SQL course badge identifies PostgreSQL specifically.
