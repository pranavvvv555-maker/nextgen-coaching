# Colour Pop AI homepage artwork

Implemented in `Components/Shared/DataAiScene.razor`, `wwwroot/js/nextgen-motion.js`, and `wwwroot/css/app.css`.

- Built-in image generation edited the selected reference into a transparent 1254 × 1254 artwork.
- Runtime asset: `src/NextGenCoaching.Web/wwwroot/images/colour-pop-ai.webp` (282,014 bytes).
- Original editable PNG: `src/NextGenCoaching.Web/wwwroot/images/colour-pop-ai.png`.
- Enhancement: the existing artwork is composed into separate SVG layers for SQL, neural network, cloud and three chart bars. One Motion timeline coordinates breathing objects, blinking database LEDs, six travelling neural signals, the AI scan, cloud delivery confirmation, sequential chart growth and floating sparkles. No additional bitmap generation was needed.
- The chart arrow is excluded from the bitmap and drawn in SVG. The local Motion engine synchronizes SQL input, chip glow, neural pulses, cloud output, and the climbing chart arrow in an 8.6-second loop.
- Playback pauses offscreen or when the page is hidden. A keyboard-accessible pause control and reduced-motion static diagram are included.
- Theme-aware CSS supports light and dark modes. The tagline and controls support English, Marathi and Hindi.
